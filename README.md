# KC Usman — Personal Profile Website

This is a Wikipedia-inspired personal biography website. It is not a Wikipedia article.

## Files
- `index.html` — website
- `assets/kc-usman-profile.jpg` — main profile photo
- `assets/kc-usman-gallery.jpg` — second photo

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account: https://github.com/
2. Create a **public** repository named exactly `YOUR-USERNAME.github.io` (replace with your GitHub username).
3. Upload `index.html` and the `assets` folder to the repository root.
4. Open repository **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Your website will appear at `https://YOUR-USERNAME.github.io/` after GitHub finishes publishing.

## Before publishing
Check that every biographical detail is accurate. Add dates for other jobs only when confirmed. Do not present learning topics as professional expertise. A public website may be indexed by search engines, but Google ranking or indexing is not guaranteed.
